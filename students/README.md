# Каталоги студентов

Для каждого студента используется каталог `students/<фамилия-инициалы>/`. Имя записывается латиницей в `kebab-case`, например `ivanov-ii`.

Создайте `README.md` с ФИО и группой в корне своего каталога и отправьте его отдельным регистрационным PR. Порядок регистрации и создания веток описан в [правилах подготовки PR](../PR-RULES.md).

## Структура лабораторной

Пример для ЛР1 Ивана Иванова, инициалы И. И.

```text
students/
└── ivanov-ii/
    ├── README.md
    └── lab1/
        ├── README.md
        ├── adapter.py
        ├── requirements.txt
        ├── source/
        │   ├── model.py
        │   ├── download_data.py
        │   └── experiment.py
        └── figures/
            └── comparison.png
```

Имена файлов внутри `source/` и расположение графиков выбирайте самостоятельно. Каталог `sources/` также допустим.

| Файл или каталог | Назначение |
|---|---|
| `students/ivanov-ii/README.md` | ФИО и группа студента |
| `lab1/README.md` | Отчёт с метриками, графиками, выводами и командами запуска |
| `lab1/adapter.py` | Точка входа для [автопроверки ЛР1](../tasks/task-01/api.md) |
| `lab1/requirements.txt` | Зависимости лабораторной |
| `lab1/source/` или `lab1/sources/` | Реализация, получение данных и запуск эксперимента |
| `lab1/figures/` | Пример каталога для необходимых графиков |

Следующие работы размещаются в `lab2/`, `lab3/` и далее. Для каждой работы создавайте отдельный PR с изменениями только её каталога.

Датасеты и локальные артефакты храните вне отслеживаемых файлов Git. Удаляйте их из истории своей ветки, если они попали в коммиты. Список запрещённых файлов приведён в [правилах подготовки PR](../PR-RULES.md#допустимые-файлы).
