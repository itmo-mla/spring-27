## С чего начать

1. Создайте fork этого репозитория в своём аккаунте GitHub.
2. Добавьте `students/ivanov-ii/README.md` со своими ФИО и группой, используя свою фамилию и инициалы в имени каталога.
3. Отправьте отдельный регистрационный PR в `itmo-mla/spring-27`, ветка `main`.
4. После принятия регистрации создайте новую ветку для лабораторной по [инструкции подготовки PR](PR-RULES.md).

Для каждой лабораторной создаётся отдельный PR. Работу принимает преподаватель после проверки кода, отчёта и устной сдачи.
