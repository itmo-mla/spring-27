# Лабораторная работа №1. Логическая классификация

Реализуйте бинарное решающее дерево с критерием Джини, вероятностной обработкой пропусков и редукцией по валидационной выборке. Сравните его с библиотечным деревом классификации.

Используйте рекурсивную схему `TreeGrowing`, обозначенную в лекции «Логические методы классификации» как ID3. Обязательная часть работы посвящена классификации: дерево может различать два класса или несколько классов.

## Порядок выполнения

1. Подготовьте датасет с количественными и категориальными признаками и пропусками в признаках.
2. Выделите обучающую, валидационную и тестовую выборки.
3. Реализуйте обучение дерева по правилам ниже.
4. Реализуйте предсказание вероятностей классов при пропусках.
5. Реализуйте редукцию дерева по правилам ниже.
6. Проведите сравнение с библиотечным деревом.
7. Подготовьте отчёт в `README.md` своей лабораторной.

## Данные и подготовка

Выберите датасет классификации из открытого источника. Укажите адрес и способ получения данных. В целевой переменной пропусков быть не должно.

Зафиксируйте разбиение и начальное состояние генератора случайных чисел. По возможности сохраните доли классов при разбиении. Обучающая выборка должна содержать все классы, представленные в эксперименте.

Обучайте преобразования данных только на обучающей выборке. Категориальные признаки передавайте собственной модели как коды категорий с указанием типов столбцов. Числовое значение кода категории не задаёт порядок. Пропуски сохраняйте как `NaN`: заполнение пропусков до передачи собственной модели не заменяет требуемую вероятностную обработку.

Обучающая выборка используется для построения дерева. Валидационная выборка используется для выбора параметров и редукции. Тестовая выборка используется для итогового сравнения после выбора параметров.

## Построение дерева

Пусть `U` — обучающие объекты, дошедшие до текущей вершины, а `p_c(U)` — доля объектов класса `c` среди них. Для каждой вершины определите распределение классов по этим объектам. При замене вершины листом используйте это распределение.

В работе используется нормировка Джини из лекции, обобщённая на несколько классов:

$$
\Phi(U)=2\left(1-\sum_c p_c(U)^2\right).
$$

Для двух классов это даёт $\Phi(U)=4p(1-p)$. Эквивалентная внутренняя нормировка допустима, если параметр `min_gain` адаптер переводит в указанную шкалу.

Перебирайте бинарные предикаты по одному признаку:

| Тип признака | Кандидаты | Ветвь 0 | Ветвь 1 |
|---|---|---|---|
| Количественный | Пороги `t` между соседними различными наблюдаемыми значениями; порог — их середина | `x_j < t` | `x_j >= t` |
| Категориальный | Каждая наблюдаемая в вершине категория `a` против остальных | `x_j != a` | `x_j == a` |

Для кандидата `f` обозначим через `U_f` объекты из `U`, у которых значение проверяемого признака известно. Пусть `U_0` и `U_1` — их разбиение по предикату. Если хотя бы одна из этих двух выборок пуста, отклоните кандидат. Для остальных рассчитайте:

$$
\operatorname{Gain}(f,U)=\Phi(U_f)
-\frac{|U_0|}{|U_f|}\Phi(U_0)
-\frac{|U_1|}{|U_f|}\Phi(U_1).
$$

Пропущенные значения исключаются только при оценке кандидата по соответствующему признаку. Они не исключают объект из всей обучающей выборки заранее. Дополнительный множитель $|U_f|/|U|$ в критерии не используется.

Выберите допустимый кандидат с максимальным выигрышем. Значения выигрыша, различающиеся не более чем на `1e-12`, считайте равными. Среди кандидатов, отстоящих от максимума не более чем на эту величину, выберите первый по порядку: индекс признака, затем порог или код категории по возрастанию.

| Условие | Действие |
|---|---|
| Все объекты `U` принадлежат одному классу | Создайте лист |
| Достигнута `max_depth` или `len(U) < min_samples_split` | Создайте лист |
| Допустимых кандидатов нет | Создайте лист |
| Максимальный выигрыш меньше `min_gain` более чем на `1e-12` | Создайте лист |
| Иначе | Создайте внутреннюю вершину и рекурсивно постройте обе ветви |

Глубина корня равна нулю. При `min_gain=0` разбиение с нулевым выигрышем допустимо, если выполнены остальные условия. Пустые ветви создавать нельзя.

## Пропуски и предсказание

После выбора предиката сохраните вероятности ветвей:

$$
q_{v0}=\frac{|U_0|}{|U_f|},\qquad
q_{v1}=\frac{|U_1|}{|U_f|},\qquad q_{v0}+q_{v1}=1.
$$

При обучении дочерних вершин используйте `U_0` и `U_1`. Объекты с пропуском выбранного признака в дочерние вершины не передавайте. Их метки учитываются в распределении классов текущей вершины. Вероятностное разветвление применяется при предсказании; дробное распределение обучающих объектов между ветвями в обязательную часть не входит.

| Условие при предсказании | Действие |
|---|---|
| Достигнут лист | Верните сохранённое в листе распределение классов |
| Проверяемое значение известно | Продолжите предсказание по соответствующей ветви |
| Проверяемое значение пропущено | Получите распределения из обеих ветвей и усредните с весами `q_v0`, `q_v1` |

Для объекта с пропуском в текущем предикате:

$$
P(c\mid x,v)=q_{v0}P(c\mid x,S_v(0))+q_{v1}P(c\mid x,S_v(1)).
$$

Применяйте это правило рекурсивно. Подстановка среднего, выбор наиболее вероятной ветви или случайный выбор одной ветви не заменяют смесь распределений.

Например, если ветвь 0 содержит три известных объекта класса 0, а ветвь 1 — один известный объект класса 1, объект с пропуском получает вероятности классов `(0.75, 0.25)`.

Предсказанный класс — класс с максимальной вероятностью. При равенстве вероятностей выберите класс с меньшей меткой. Вероятности должны быть неотрицательными и давать единицу в сумме по всем классам.

## Редукция дерева

Выполните один проход снизу вверх: сначала обработайте ветвь 0, затем ветвь 1, затем текущую вершину. Для каждой внутренней вершины рассмотрите четыре варианта:

1. Сохранить её текущее поддерево.
2. Заменить его текущим поддеревом ветви 0.
3. Заменить его текущим поддеревом ветви 1.
4. Заменить его листом с распределением классов по обучающим объектам исходной вершины.

Для каждого варианта временно замените соответствующий фрагмент дерева и посчитайте число ошибок **всего полученного дерева на всей валидационной выборке**. Для объектов с пропусками используйте смесь распределений и последующий выбор класса. Такая оценка учитывает влияние замены на итоговое предсказание объекта.

Выберите вариант с наименьшим числом ошибок. При равенстве выберите вариант с меньшим числом вершин. Если равны оба показателя, используйте порядок: новый лист, ветвь 0, ветвь 1, сохранение поддерева.

При замене дочерним поддеревом сохраняйте его параметры без переобучения. Распределения в новых листьях и вероятности сохранённых ветвей не оценивайте по валидационным меткам. Для пустой валидационной выборки результат редукции — один лист с обучающим распределением классов в текущем корне до редукции.

Сохранение поддерева всегда входит в число вариантов, поэтому редукция не должна увеличивать валидационную ошибку или число вершин. Улучшение тестовой метрики не гарантируется и не является условием приёмки.

## Эксперимент и отчёт

Для библиотечного эталона используйте `sklearn.tree.DecisionTreeClassifier` с критерием Джини. Для него допускается отдельная подготовка категориальных признаков и пропусков библиотечными средствами. Настраивайте её только по обучающей выборке. Укажите различия в подготовке данных: библиотечный эталон не обязан повторять вашу вероятностную обработку пропусков.

На одном разбиении сравните собственное дерево до редукции, собственное дерево после редукции и библиотечное дерево. В отчёте приведите:

- источник данных, типы признаков, доли пропусков и размеры трёх выборок;
- параметры и описание подготовки данных;
- `accuracy` и `macro-F1` на валидационной и тестовой выборках;
- число вершин, число листьев и глубину каждого дерева;
- вывод о влиянии редукции на качество и размер дерева.

Покажите зависимость валидационной ошибки и числа вершин от максимальной глубины собственного дерева. Выберите параметры по валидационной выборке. Для итогового сравнения используйте сохранённое дерево до редукции и полученное из него дерево после редукции. Подпишите оси и обозначения на графиках.
